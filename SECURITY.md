# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately through [GitHub Security Advisories](https://github.com/kerstz/personal-portfolio/security/advisories/new). Include:

- a description of the issue and its impact,
- steps to reproduce or a proof of concept,
- the affected commit or version.

You should receive an answer within a few days. Once a fix is available, the issue will be disclosed and credited if you wish.

## Supported versions

Only the latest commit on `main` is supported.
